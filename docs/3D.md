# 3D: opt-in per project, never in `package.json` here

`react-three-fiber` and `drei` are **not installed** in this template, and that
is the deliverable, not an omission. HOUSE-STYLE 12: zero of three professional
sites ship 3D, two of eight trendy sites do, and the base bundle for a non-3D
project must contain no three.js, no react-three-fiber, no drei and no Draco
decoder. Gate **G40** scans the built bundle for exactly that, and
`npm run check:libs` runs it.

The ESLint config also blocks `import ... from "three"` and `@react-three/*`
outright, so an accidental top-level import fails lint before it reaches a
bundle.

## Four gates before a project earns it

All four must pass. This is not a taste call.

1. **The object is the subject of the business, not an ornament.** ocha is a
   matcha bar and the object is a whisk. beanro is a coffee shop and the object
   is a cup. A floating abstract shape or a generic laptop is a no.
2. **It has real scroll distance and it does work in that distance.** ocha's
   whisk is pinned for 2,814px, 16.8% of the page, with review cards flying
   over it. A pinned sequence must deliver more than one idea per ~600px, so
   2,814px of pin needs at least five distinct beats.
3. **The model is a Draco-compressed `.glb`.** An uncompressed GLTF fails the
   budget.
4. **It is code-split and lazy.**

Every 3D element also counts against the motion budget. A pinned model is PIN
plus the model plus whatever flies over it, which on the trendy pole's budget
of five leaves room for one more behaviour and no more.

## The cheap half of the bet, and usually the right one

A `ShaderMaterial` on a `PlaneGeometry` with a `uProgress` uniform and a
displacement map, crossfading between images, needs **no loader, no Draco and
no model**, and it delivers the effect Mauricio named first ("the animation
that changes the images on the hero"). ocha ships exactly this as a second
WebGL canvas. If a project wants the 3D feeling on a budget, ship the shader
plane and skip the GLB.

## The install

```bash
npm i three @react-three/fiber @react-three/drei
npm i -D @types/three
```

Then add the route to the exemption when you run the gate, so the base-bundle
check still applies everywhere else:

```bash
npm run build && node scripts/check-banned-libs.mjs --route <your-3d-route>
```

## The code-split pattern

`next/dynamic` with `ssr: false`, mounted on an IntersectionObserver so the
chunk is not even requested until the section approaches.

```tsx
// src/components/hero/Hero3D.tsx
"use client";

import dynamic from "next/dynamic";
import { useEffect, useRef, useState } from "react";

// ssr:false is mandatory. A WebGL canvas has no server render, and without it
// Next tries to evaluate three.js in the RSC layer.
const Scene = dynamic(() => import("./Scene"), {
  ssr: false,
  // 12.4: a poster frame is MANDATORY. Reduced motion turns the canvas off and
  // a canvas that fails to initialise must not leave a hole. Ship a static
  // image at the canvas's exact dimensions behind it.
  loading: () => <img src="/3d-poster.jpg" alt="" width={1200} height={800} />,
});

export function Hero3D() {
  const ref = useRef<HTMLDivElement>(null);
  const [near, setNear] = useState(false);

  useEffect(() => {
    const el = ref.current;
    if (!el) return;
    const io = new IntersectionObserver(
      ([e]) => e.isIntersecting && (setNear(true), io.disconnect()),
      { rootMargin: "200px" },
    );
    io.observe(el);
    return () => io.disconnect();
  }, []);

  return (
    <div ref={ref}>
      {near ? <Scene /> : <img src="/3d-poster.jpg" alt="" width={1200} height={800} />}
    </div>
  );
}
```

Reduced motion (8.8): the canvas is **off entirely** and the poster frame
renders instead. Read `useReducedMotion()` in `Hero3D` and skip the dynamic
import when it is true.

## The budget

**1.1 MB of 3D JavaScript, gzipped and code-split. That is a ceiling, not a
target.** beanro's measured chunk is 1,084,812 bytes; ocha's is 927,598. Gate
G41 fails above it.

One canvas per page, one model. Use `useGLTF`, `useFrame` and `<ScrollControls>`
rather than raw three.js: the two reference sites use raw three only because
they are Framer code components with no React tree to attach to. We have one.
